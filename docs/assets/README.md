## Comment capturer

- **Téléphone Android** : boutons _Volume bas + Marche/Arrêt_ simultanément.
- **Émulateur Android Studio** : icône appareil photo dans la barre latérale de l'émulateur.

Renommer chaque capture selon le tableau ci-dessus et la déposer dans ce dossier.

## Recommandations

- Ne faire figurer **aucune donnée personnelle réelle** : utiliser exclusivement les comptes de démonstration.
- Format PNG, résolution native de l'appareil.
